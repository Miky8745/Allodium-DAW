# Bloom instrument presets

Each `.sfz` file here is a preset for Bloom, Allodium's instrument
(see `docs/instrument.md`). The first folder level is the category shown in
the preset browser.

The starter presets only reference the bundled LMMS samples in
`data/samples/` (GPL-2.0-or-later, see `data/samples/CREDITS.md`). Only add
presets and samples that may be redistributed (CC0 preferred). Keep personal
or non-redistributable libraries in `data/samples/local_samples/`, which is
gitignored.
